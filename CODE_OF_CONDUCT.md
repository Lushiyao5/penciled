# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. Everyone who takes part in the project is expected to follow it.

## Reporting

To report unacceptable behaviour, contact the maintainer privately through [GitHub](https://github.com/marcellosso). All reports will be reviewed promptly and kept confidential.
